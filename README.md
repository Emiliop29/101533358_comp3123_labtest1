# COMP3123 - Lab Test 1

JavaScript ES6 and Node.js exercises.

## Run

Requires Node.js. From the project folder:

```bash
node question1.js
node question2.js
node add.js
node remove.js
```

- **Question 1:** `lowerCaseWords` returns a Promise, filters out non-strings and converts strings to lowercase. Rejects invalid non-array inputs.
- **Question 2:** two separate Promises resolve/reject after 500 ms; both outcomes are handled.
- **Question 3:** `add.js` creates `Logs`, changes the working directory and writes 10 text files. `remove.js` prints each filename, deletes each file and removes the directory. Run `add.js` before `remove.js`.
